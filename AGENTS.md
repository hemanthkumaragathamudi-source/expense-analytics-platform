# AI Coding Agent Instructions

Welcome to the Personal Finance & Expense Analytics Platform!

## Project Overview
This is a minimalist expense tracking and analytics dashboard to visualize personal finance habits.

## Repository Structure
- `backend/`: Application backend code.
- `frontend/`: Application frontend code.
- `database/`: Database schema, migrations, and seed data.
- `docs/`: Project documentation.
- `tests/`: End-to-end tests and test fixtures.

## Instructions
1.  **Code Organization**: Respect the existing folder structure. Code related to the backend should go into `backend/`, and frontend code into `frontend/`.
2.  **Testing**: Ensure that you include appropriate tests in the `tests/` directory or within the respective application directories as needed.
3.  **Documentation**: Keep documentation in the `docs/` folder up to date with any architecture or setup changes.
4.  **Before Merging**: Verify that all tests pass and follow the pre-commit instructions before finalizing changes.
